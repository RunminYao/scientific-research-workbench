# Orient Codex and Subagents

Use project evidence to place a task before local technical detail dominates the reasoning. This is most useful for long or historically entangled tasks, independent reviews, and work adjacent to stopped routes; it is not a required ceremony for every small subtask.

## Recover independently

- Start from the repository path, raw task, and project authorities when possible. Treat a parent agent's diagnosis as a hypothesis unless the task explicitly establishes it.
- Recover the central question, current decision, evidence-backed result spine, matching stopped routes, and active gap before choosing a continuation.
- Identify the minimum source, derivation, calculation, or verifier needed to understand the assigned task. Avoid loading the entire repository merely to appear comprehensive.

## Place the task

Form a compact working brief that makes clear:

- what scientific decision the task can affect;
- which established result or assumption it consumes;
- what a pass, failure, or ambiguous outcome would change;
- which claims remain downstream or out of scope;
- which stopped or superseded method must not be repeated without new evidence.

Use the brief internally and proceed with the assigned work when execution is authorized. Return it explicitly when the request is for orientation, review, delegation setup, or trajectory audit.

## Check for local fixation

Ask whether local progress changes the named observable or decision, whether success still lacks a required physical or mathematical bridge, and whether the proposed method is a disguised repeat of a stopped route. Redirect the framing when the evidence supports it; do not reject a task merely because it is technically narrow.

For an independent navigator or forward test, pass minimal parent context and raw artifacts rather than the expected answer. Report conflicts between guidance and authority instead of choosing whichever best matches the assignment.

Ordinary subagents should not edit project-wide orientation or notice files. Return a candidate notice or correction to the primary agent unless explicit integration ownership was assigned.
