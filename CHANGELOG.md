## [0.5.0] - 2026-09-04

### Initial public release

- Added evidence-aware scientific project orientation and claim calibration.
- Added workflows for literature research, analytical derivation, scientific computation, independent verification, citation management, and LaTeX manuscript editing.
- Added a unified manuscript-project scaffold with generic, HEP/astrophysics, and axion-phenomenology profiles plus optional tool adapters.
- Added conservative bibliography, notation, link, and result-synchronization audits with explicit unsupported-syntax reporting.
- Added preview-first mutation, bounded JSON/JUnit verification reports, secret-aware command previews, regression tests, examples, and CI.

## Version policy

- The plugin remains pre-1.0. Minor releases may contain breaking changes, but each such change must include a migration note.
- Patch releases are backward-compatible corrections.
- `.codex-plugin/plugin.json` is the release-version source of truth.
